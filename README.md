# Claude Agent 订票 40 例（国内日常可行版）

> Claude Agent Booking — 40 Practical Examples (China-Daily-Feasible Edition)
>
> 用 Claude（CLI / MCP + Playwright MCP）构建"帮我订机票" agent 的 **40 个具体、可运行**例子教学材料。坚持国内可行：**不注册国外平台**，只用 Playwright + 携程/飞猪/去哪儿 + 钉钉/飞书群机器人；诚实标注每例是"✅ 可直接跑 / ⚠️ 需人类介入 / ❌ 当前不可行"。

## 核心结论（三句话）

1. Claude 能替你**查、替你比、替你填表**，但不能替你输密码付款
2. 全部用国内工具（Playwright MCP + 携程/飞猪/去哪儿 + 钉钉/飞书），不注册任何国外平台
3. 40 个例子分三档：可直接跑 / 需人类某步介入 / 当前不可行

## 交付物结构

- **第 0 节** 三句话结论
- **第 1 节** 环境与配置（所有例子共同前置：Playwright MCP 配置、钉钉/飞书 webhook、免注册）
- **第 2 节** 40 个例子，按链路环节分 7 组（全部国内可行）：
  - 组1 航班查询（Playwright + 携程/飞猪/去哪儿）· 例1–8
  - 组2 数据整理（本地文件/比价排序/筛选）· 例9–16
  - 组3 决策辅助（Top-3 推荐 + 用户确认）· 例17–20
  - 组4 通知（钉钉/飞书 webhook）· 例21–25
  - 组5 浏览器自动化进阶（登录/填表/历史订单，密码验证码留给人）· 例26–30
  - 组6 端到端编排（查询→整理→推荐→通知 / 定时 / 阈值提醒）· 例31–34
  - 组7 边界与反例（验证码/支付/自动下单等不可行项）· 例35–40

## 诚实边界（不做的事）

- 真实下单（必须用户本人登录 + 验证码）、真实支付（必须用户输密码）
- 端到端全自动一句话出订单号（当前不存在）
- 绕过反爬 / CAPTCHA（需特殊基础设施）
